# High-Level Visual Memory Report

Rendered report: https://233333nmc.github.io/highlow-handoff/

Open `index.html` in a browser to view the static report for the incremental
subtask-planning experiment. It includes the measured n=3 interaction latency,
the historical n=10 completion-detection table, exact model prompts and raw
outputs, and the camera frames sent to the verifier.

The representative rollout video for each displayed example is stored under
`assets/rollouts/` and embedded directly in the report. Raw JSONL logs, model
checkpoints, caches, and simulator output directories remain intentionally
excluded.

GitHub Pages publishes this directory directly, so the deployed site opens the
report at its root URL.
